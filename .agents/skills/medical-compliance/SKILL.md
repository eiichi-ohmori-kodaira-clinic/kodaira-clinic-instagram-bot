# 3省2ガイドライン準拠ルール

## 1. 端末内データ保持の禁止
* AndroidアプリおよびWeb画面（Local/Session Storage, IndexedDB）において、患者の個人情報や医療検査記録を暗号化せずに保存・キャッシュしてはならない。
* 一時ファイルを作成した場合は、処理完了後に必ず即時削除するロジックを組み込むこと。

## 2. 通信とデータの暗号化
* すべての通信は TLS 1.3（最低 TLS 1.2）を強制する。
* 共有ドライブ上のファイルやデータベース内の平文データ（氏名、カルテID、検査結果）は AES-256 で暗号化する。

## 3. アクセス制御と監査
* 操作ログ（誰が・いつ・どの患者データに・何をしたか）を最低5年間保持できる構成とする。
